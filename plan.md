# Plan de trabajo — Tienda Shopify (Colombia)

## Objetivo
Montar una tienda Shopify funcional con 20 productos y pagos configurados mediante Shopify Payments. Lanzamiento rápido y gestionado.

## Tareas y estimaciones
1. Preparación (0.5 día)
   - Crear cuenta Shopify y escoger plan.
   - Definir dominio y datos de contacto.

2. Configuración básica (1 día)
   - Configurar Shopify Payments, impuestos y envíos para Colombia.
   - Añadir políticas (Política de privacidad, devolución, términos).

3. Productos (1-2 días)
   - Preparar CSV con 20 productos y subir imágenes.
   - Revisar variantes y stock.

4. Diseño y Theme (1 día)
   - Seleccionar o instalar un theme (gratuito o premium).
   - Personalizar colores y tipografías.

5. Pruebas y QA (0.5 día)
   - Realizar pedidos de prueba y verificar emails.
   - Comprobación de SEO básico y meta tags.

6. Preparación al lanzamiento (0.5 día)
   - Configurar dominio y SSL.
   - Revisar analítica (Google Analytics / GA4) y píxeles.

7. Lanzamiento
   - Activar tienda, anunciar en redes y monitorizar problemas.

## Roles y accesos
- Necesitaré acceso de colaborador o credenciales de API si quieres que haga la importación automática.

## Entregables
- `products-template.csv` con los 20 productos listos para importación.
- Checklist de lanzamiento completada.
- Repositorio con documentación y, opcionalmente, el theme versionado.

**Fecha objetivo sugerida:** 7–10 días desde la confirmación (dependiendo contenido y imágenes).
