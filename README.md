# Tienda InnovatecJD

**Plataforma:** Shopify
**País de operación:** Colombia
**Pasarela de pagos preferida:** Shopify Payments (compatible con Stripe/PayPal)
**Número aproximado de productos:** 20
**Logo / imágenes:** No disponibles aún

## Resumen
Esta carpeta contiene la documentación y plantillas para montar la tienda en Shopify de forma rápida y gestionada. Encontrarás un plan de trabajo, una plantilla CSV para importar productos y una checklist de lanzamiento.

## Archivos importantes
- `plan.md` — Plan de trabajo y tareas con tiempos estimados.
- `products-template.csv` — Plantilla para importar productos a Shopify.
- `launch-checklist.md` — Checklist paso a paso para el lanzamiento.
- `assets/images/` — Carpeta para subir las imágenes de los productos.

---

## Guía de inicio rápida ✅
1. Crea una cuenta en Shopify (https://www.shopify.com) y selecciona un plan.
2. Añade a tu colaborador o comparte acceso si quieres que configure la tienda.
3. Configura Shopify Payments (o Stripe/PayPal si lo prefieres). En Colombia, verifica las condiciones de Shopify Payments y la conversión de moneda.
4. Prepara las imágenes (ideal: 2400x2400 para productos) y súbelas a `assets/images/`.
5. Completa `products-template.csv` y usa la importación de productos en Shopify Admin (Productos > Importar).
6. Configura envíos y tasas para Colombia (Ajustes > Envíos y entrega / Impuestos).
7. Prueba un checkout con un pedido de prueba (usar modo test en pasarela de pagos).
